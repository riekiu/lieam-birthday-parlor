# Lieam's Birthday Parlor

A little birthday storybook and photobooth, built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser or serve this folder with any static web server.

## Publish with GitHub Pages

The workflow in `.github/workflows/pages.yml` deploys this folder to GitHub Pages whenever a commit is pushed to `main`. Enable GitHub Actions for Pages as the repository's Pages build and deployment source in repository settings if it is not already enabled.

The photobooth camera is optional. Visitors can choose a local image instead; photos are not uploaded or saved by the site unless downloaded.
